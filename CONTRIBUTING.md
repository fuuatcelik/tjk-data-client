# Katkı rehberi

1. Depoyu fork edin ve konuya özel bir dal açın.
2. Davranış değişikliklerine test ekleyin.
3. `npm run check` komutunun geçtiğini doğrulayın.
4. Küçük, açıklayıcı commit'lerle pull request açın.

Gizli anahtarları, gerçek kullanıcı verilerini veya TJK'den alınmış büyük yanıt örneklerini depoya eklemeyin.
