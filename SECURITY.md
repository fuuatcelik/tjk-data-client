# Güvenlik

Güvenlik açığını herkese açık issue olarak paylaşmayın. Depo sahibi GitHub hesabını ekledikten sonra bu dosyaya özel bildirim adresini yazmalıdır.

Kimlik anahtarlarını loglara, hata raporlarına veya test fixture'larına koymayın. Bir anahtar yanlışlıkla yayımlandıysa Git geçmişini temizlemekle yetinmeyin; anahtarı sağlayıcı tarafında iptal edip yenileyin.
